# Programming Books

[Português / original catalog](README.md) | **English**

A fork containing a programming-book catalog and study materials in Portuguese and English. The original README groups links by subjects such as algorithms, programming logic, frontend development, JavaScript, C#, PHP, Python and Java.

## Navigate the collection

See the [original catalog](README.md) for its existing title list and references. This English overview does not change or translate the books themselves.

## Context and ownership

This is a third-party collection, not an application developed by the fork owner. Book authorship remains with the respective authors and publishers. This documentation does not grant rights to redistribute or reuse the books.

Potential study topics include programming fundamentals, software design, web development and organizing a reading plan; this overview does not claim that every listed work has been read.

No installation or application build is required to read the repository documentation.
